Beyond enabling operations, **AI Tools → AI Image Pro → Settings** has four more tabs for controlling limits, storage, watermarking, and the public-facing landing page.

## Setting size and daily limits

**Limits** tab: Max Upload Size, Max Input Dimension, and Max Output Dimension (in pixels) cap what customers can send in and get back. **Guest Daily Operation Limit** and **Free Users Daily Operation Limit** cap usage per day for each tier — and if you sell paid plans, **Per-Plan Daily Limits** let you set a separate cap for each one.

## Controlling storage and auto-deletion

**Storage** tab: set separate auto-delete windows (in days) for Guest, Free, and Premium users' generated images — leave a window at 0 to keep images forever for that tier. **Max Library Storage per User** caps how much space one account's library can use. You can also set the thumbnail size and choose whether results auto-save to the customer's library.

## Watermarking free downloads

**Watermark** tab: turn on **Watermark Free-User Downloads** to stamp a logo or text onto images downloaded by non-paying customers — Premium users' downloads are never watermarked, regardless of this setting. Choose a logo image (or fall back to text), position, and opacity.

## Building reusable style presets

**Style Presets** tab: create named prompt styles (a name, a prompt suffix, an optional negative prompt, and a thumbnail) that customers can apply with one click in the Studio instead of typing style instructions themselves.

## Customizing the public landing page

**Landing Page** tab: every section of your public `/ai-image` marketing page is editable here — hero heading and subheading, example prompts, feature rows, use cases, benefits, how-it-works steps, an FAQ pulled from your site's FAQ manager, a call-to-action banner, and its own SEO title/description with a live preview.

## Why images are disappearing or storage limits are hit

- A customer's images vanished after some time — check the **Storage** tab's auto-delete window for their tier; a value other than 0 deletes images automatically after that many days.
- **Max Library Storage per User** was reached — new saves may fail or older items may need to be removed first.
- Downloads look watermarked when they shouldn't — confirm the customer's account is actually on a Premium/paid access level, since only Premium is exempt from the watermark toggle.
