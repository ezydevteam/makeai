**Admin → Appearance → Menus** and **Sidebar** build the navigation and widget areas shown across your public site — separate from the admin panel's own left-hand navigation.

## Building a navigation menu

A **Menu** is a named, ordered tree of links you can assign wherever a menu picker appears — the theme's header navigation, the footer's bottom bar, or a footer "Menu" content block. Add items with **Add Link**, or use the **Quick Add** panel to one-click-add any existing Page, AI category, or blog category. Each item can be a Custom URL, a CMS Page, or a named internal Route, and can be nested up to two levels deep — drag items to reorder or re-nest them. Top-level items also support a **Mega Menu** layout (up to 4 columns) for larger dropdown menus.

## Adding widgets to the sidebar

**Sidebar** is a separate builder for the widget areas shown on the public site — not the admin panel's menu. It has three independent areas: **Main** (AI tool pages), **Blog** (blog listing and posts), and **Page** (custom pages), each with its own widget stack. Add widgets from a library that includes Search Box, Tool Categories, Popular Tools, Recent Tools, Recent Blog Posts, Tag Cloud, Blog Categories, Newsletter, Social Follow, an Ad Zone, and Custom HTML — drag to reorder, click to edit each one's own settings.

## Why a menu or widget isn't showing

- A menu was built but never actually **assigned** anywhere — building it under Menus doesn't place it anywhere on its own; pick it from the relevant "Menu Source" dropdown in Theme Settings.
- A sidebar widget was added to the wrong **area** (Main, Blog, or Page) — check you're editing the area that matches the page type you're viewing.
- A menu item's **Visibility** is set to Guests-only, Logged-in-only, or Premium-only, and the account you're testing with doesn't match.
