Installation Wizard

MakeAI comes with a beautiful 7-step installation wizard. Once complete, the /install route returns 404 — it can never be re-accessed.

ℹ️
Before you beginThe installer automatically generates APP_KEY, runs all migrations, and sets INSTALLED=true in your .env. You only need to complete this once.

Step-by-step walkthrough

1
System Requirements Check
The wizard checks PHP version (8.3+), required extensions (curl, zip, gd, mbstring, redis, pdo_mysql), and writable directories. All checks must be green to proceed. Red items show a fix suggestion.
2
Database Configuration
Enter your MySQL 8+ credentials — host, port, database name, username, password. The wizard tests the connection live before proceeding. A failed connection shows the exact MySQL error.
3
Site Setup
Set your site name, URL, timezone, and mail driver (SMTP/Mailgun/SES). These values populate the settings table — nothing is hardcoded. You can change them later from Admin → Settings.
4
License Activation
Enter your Envato purchase code. The wizard calls the Envato Market API to verify, then stores the encrypted license in the settings table. Regular license → core features. Extended license → subscription/billing system unlocked.
5
Admin Account Creation
Creates the Super Admin account. This uses the separate admins table and guard — completely isolated from user auth. Email + password + confirm password required.
6
Demo Data (Optional)
One-click demo install seeds 50 sample users, 200 documents, 30 blog posts, and 12 months of realistic revenue data. If one-click fails, manually upload the included demo.sql file. Migration conflicts are auto-resolved.
7
Final Setup & Launch
Runs php artisan migrate --force, generates APP_KEY, sets INSTALLED=true, clears all caches. Redirects to admin dashboard on success. The /install route now returns 404.

What the wizard writes to .env

.env 
# Auto-generated by installer
APP_NAME="MakeAI"            # from settings table, not this value
APP_KEY=base64:xxxxxxxxxxxx   # auto-generated
APP_URL=https://yourdomain.com
INSTALLED=true                # blocks /install route after completion

DB_HOST=127.0.0.1
DB_DATABASE=makeai
DB_USERNAME=makeai_user
DB_PASSWORD=your_password

CACHE_STORE=redis
SESSION_DRIVER=redis
QUEUE_CONNECTION=redis

# Reverb WebSocket (auto-filled by installer)
REVERB_APP_ID=makeai
REVERB_APP_KEY=xxxxxxxxxxxx
REVERB_APP_SECRET=xxxxxxxxxxxx
REVERB_HOST=127.0.0.1
REVERB_PORT=8080
⚠️
Never commit .env to version control. The distributed zip includes only .env.example with all variables documented and placeholder values.

Post-install checklist

  • ✓ Set up cron: * * * * * php artisan schedule:run
  • ✓ Start Horizon: php artisan horizon (via Supervisor)
  • ✓ Start Reverb: php artisan reverb:start (via Supervisor)
  • ✓ Start SSR: php artisan inertia:start-ssr (via Supervisor)
  • ✓ Add at least one AI provider API key in Admin → Settings → Integrations
  • ✓ Configure mail driver in Admin → Mail → Configuration
  • ⚠ Verify APP_DEBUG=false in production
  • ⚠ Confirm storage/ and bootstrap/cache/ are writable

Server Requirements

MakeAI runs on any PHP 8.3+ server. Redis is mandatory — file driver is not supported in production.

Minimum requirements

🐘
PHP
8.3+ (8.4 supported)
🗄️
MySQL
8.0+ or MariaDB 10.6+
⚡
Redis
7.0+ (cache, queues, sessions)
🟢
Node.js
18+ (for Inertia SSR)
💾
Storage
2GB+ recommended
🔌
Open Port
8080 for Reverb WebSocket

Required PHP extensions

bash
# Check all required extensions
php -m | grep -E 'curl|zip|gd|mbstring|redis|pdo_mysql|fileinfo|tokenizer|xml|bcmath|openssl'

# Required: curl, zip, gd, mbstring, pdo_mysql
# Required: redis (phpredis or predis), fileinfo, tokenizer, xml, bcmath, openssl

License Activation

MakeAI uses Envato's purchase code system. License type determines which features are available — particularly the subscription/billing system.

License types

📄
Regular License
get_license_type() === 1
All core AI tools, admin panel, user management, blog, support tickets. Subscription billing system is hidden.
⭐
Extended License
get_license_type() === 2
Everything in Regular + subscription plans, payment gateways, billing UI. Unlocks when isProAvailable() returns true.
✅
isProAvailable() rule Returns true only when: is_extended_license() === true AND settings('subscriptions_enabled') === true. Every subscription UI element must be gated behind this — hidden when false, never just disabled.

Configuration

All site configuration lives in the settings table — not in .env. Use the settings() helper everywhere.

The settings() helper

php
// Read a setting (Redis-cached, never hits DB)
settings('site_name')                    // → 'MakeAI'
settings('openai_key')                   // → decrypted API key
settings('max_tokens', 2000)             // → fallback if null

// Write a setting (updates DB + clears cache)
settings_set('site_name', 'My Platform')
settings_set('openai_key', 'sk-...', 'encrypted')

// NEVER hardcode the app name:
// ❌ echo 'Welcome to MakeAI';
// ✅ echo 'Welcome to ' . settings('site_name');

Architecture Overview

MakeAI is built on Laravel 13 + Inertia.js SSR + Vue 3. These are the non-negotiable architectural rules.

ℹ️
Full spec in AI_SaaS_Master_Prompt.md — Part 01 (Tech Stack) and Part 04 (Foundation Layer). This page is a quick reference summary.

9 named queues

horizon.php
otp        → 3 workers, 1 retry, 30s timeout (OTP must be instant)
ai         → 5 workers, 2 retries, 120s timeout
media      → 3 workers, 2 retries, 300s timeout (video generation)
emails     → 3 workers, 3 retries, 60s timeout
webhooks   → default workers
social     → default workers
embeddings → default workers
default    → 4 workers
low        → 1 worker (view counts, analytics)
